I'm Sumsam Ali, a Development Manager, Data leading a team that architects enterprise-scale, multi-modal RAG platforms on Microsoft Fabric and Azure OpenAI 🤖. My work sits at the intersection of LLM orchestration, data engineering, and applied AI — turning fragmented enterprise content into retrieval systems people actually rely on 📊.

I started at FAST NUCES, Karachi, where I built an adaptive AI soft-skills assessment engine (Zephyr-7B + LoRA + Item Response Theory) as my thesis, alongside a multilingual multimodal olfactory-detection research project 🎓. Since then I've architected production RAG systems for Fortune 1000 clients, led data migrations processing millions of rows daily, and shipped AI assistants adopted by hundreds of internal users 🚀.

I hold Microsoft's Azure AI Engineer, Fabric Data Engineer, and Fabric Analytics Engineer certifications, alongside DeepLearning.AI's Deep Learning, Machine Learning, and LLM Fine-Tuning specializations 🏅. These days I spend most of my time on agent orchestration (LangChain / LlamaIndex / LangGraph), hybrid retrieval (BM25 + vector search), and CI/CD for data platforms.
